# Christmas Postcard Creator

Generate beautiful AI-powered Christmas postcards with personalized names, wishes, and messages.

[![Built with Pollinations](logos/built-with-pollinations.svg)](https://pollinations.ai)

## Try it now

**Live app:** [https://christmas-card-creator.up.railway.app](https://christmas-card-creator.up.railway.app)

## Features

- Watercolor and gouache art style
- Personalized recipient names
- Custom wishes visualized as gifts
- Personal messages
- High-resolution output (1536x1024)
- Instant generation

## Free to use

This project is **free and open source**. Feel free to use, modify, and share.

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- AI: [Pollinations](https://pollinations.ai) API
- Hosting: Railway
